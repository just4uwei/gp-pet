# GP Pet

> 桌面桌宠形态的 A 股量化信号提醒工具。
> 跟踪自选股 · 量化策略判断买卖时机 · 不打断工作的提醒 · 本地存储 · 免登录 · **不接券商、不下单**

   │  金叉突破 · 趋势市    │
   │  置信 78%             │
   ╰──────────┬────────────╯
              ▼
            (｀･ω･)          ← 桌宠：透明置顶、点击穿透、双击静默

## 状态

**M0 · 工程骨架**。设计文档已完备，`src/` 下为类型契约与目录占位，尚无业务实现。

里程碑与出口条件见 [docs/08 开发路线图](./docs/08-开发路线图.md)。

## 它做什么

1. 跟踪你手工添加的自选股（沪深京 A 股与 ETF，上限 100 只）
2. 在交易时段按分层量化策略计算买卖信号：
   指标（MA / MACD / BOLL+带宽分位 / ADX+DMI / RSI / 量能）
   → 市场状态（趋势 / 震荡 / 转折）
   → 策略（趋势跟踪 + 均值回归 + 多周期共振）
   → 动态权重与投票组合
   → 风控闸门
3. 分三级提醒：表情变化（静默） / 气泡（无声自动消失） / 系统通知（仅高置信与止损）
4. 全部数据落在本机，无账号、无服务端、无遥测

## 它不做什么

不下单、不接券商、不做资金归集、不做云同步、不做全市场选股、不做移动端。

## 快速开始

```bash
pnpm install
pnpm dev            # 启动桌宠
pnpm test           # 引擎单测（不需要启动 Electron）
```

> `package.json` 中的依赖版本为占位值，首次安装前建议用 `pnpm dlx npm-check-updates` 校准。
> `better-sqlite3` 为原生模块，需在 Electron ABI 下重建。

## 关于策略的诚实说明

本项目的策略框架来自根目录的 `量化策略买卖时机判断.docx`（[归档版](./docs/reference/量化策略买卖时机判断.md)）。该文档标注为 AI 生成，其中所有绩效数字（年化 17.33%、胜率 58%、信息比率 1.96 等）均引自网络文章，**无原始数据、无法复现**。

本项目的处理方式（[ADR-0003](./docs/adr/ADR-0003-来源文档数值不作为出厂默认.md)）：

- **采纳**其规则结构 —— 分层组织、按市场状态切换策略权重、投票确认、三级风控
- **不采纳**其任何绩效数字作为事实，也不以其参数值作为出厂默认
- 所有参数视为待标定的初始猜测，出厂默认值由本地回测产出

因此回测 CLI 是 M2 的必交付项，而非可选功能。
