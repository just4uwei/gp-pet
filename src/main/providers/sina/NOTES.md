# sina · 接口笔记

**最后核对：2026-08-11**（真实响应已录制到 `tests/fixtures/providers/sina/`）

角色：备源。**只承担批量快照**。

## 端点

```
GET https://hq.sinajs.cn/list=sh600000,sz000001,...
Referer: https://finance.sina.com.cn
```

- 编码 **GBK**。
- **Referer 是必需的**，缺了返回 403。这是接口方明确的调用要求，是 docs/03 §2.4
  「不伪造 Referer 之外的任何身份信息」里允许的那一项。
- 分片 ≤ 50 只/请求。

## 字段（`var hq_str_sh600000="…"`，逗号分隔）

| 下标 | 含义 |
|---|---|
| 0 | 名称 |
| 1 | 今开 |
| 2 | 昨收 |
| 3 | 最新价 |
| 4 / 5 | 今日最高 / 最低 |
| 6 / 7 | 买一价 / 卖一价 |
| 8 | 成交量，**股**（腾讯给的是手） |
| 9 | 成交额，**元** |
| 10–19 | 买一~买五的 (量股, 价) |
| 20–29 | 卖一~卖五的 (量股, 价) |
| 30 / 31 | 日期 `YYYY-MM-DD` / 时间 `HH:mm:ss`（北京时间） |
| 32 | 状态位，正常为 `00`，停牌的 bj430047 为 `-3`。含义未确认，**代码未依赖它** |
| 33 | `D\|量\|额` 尾串，含义不明，不用 |

## 已知怪癖

1. **不提供涨跌停价**，全部本地算（`src/core/code.ts priceLimits`）。
2. **未上市 / 长期停牌的代码返回一整行 0**：fixture 里 `bj430047` 的价格全是 `0.000`，
   日期停在 `2026-06-25`，字段数也短一截（33 而非 34）。
   这种记录**整条丢弃**而不是落库 —— 昨收写成 0 会连带污染涨跌停与止损判定。
3. 成交量与腾讯有零头差异：腾讯按手取整（`509424` 手），新浪给到股（`50942433` 股）。
   两源一致性校验（docs/03 §2.2）比对最新价，不比对成交量。
4. 成交额与腾讯 57 号字段（万元，4 位小数）换算后完全一致，可用于交叉校验。
5. **不承担日线**：新浪历史数据是另一套接口（JS 包装、复权口径不明）。
   为一个备源引入第二套解析器不值得，`capabilities.daily = false`，
   `fetchDaily` 直接抛 `UnsupportedCapabilityError`。
6. 基础信息只有名称与板块，没有行业与上市日。
