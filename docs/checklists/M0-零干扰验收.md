# M0 出口验收 · 零干扰契约

[docs/06 §1](../06-桌宠交互与非干扰设计.md) 要求把 C1–C10 逐条写成手工验收清单。本文件是 M0 的那一份。

**M0 的出口条件只有两条：C1 与 C2 在真机验证通过。** 这两条若做不到，桌宠形态存疑，
应按 [docs/08 关键决策点 1](../08-开发路线图.md) 改为托盘 + 轻量悬浮条，而不是继续往上堆功能。

其余契约在 M0 只做「不倒退」检查，完整验收随对应里程碑推进。

```bash
pnpm dev        # 开发模式会显示命中区虚线框与状态角标，便于肉眼对齐
```

---

## 必须通过（M0 出口）

| # | 契约 | 操作 | 通过标准 |
|---|---|---|---|
| C1 | 永不抢焦点 | 在记事本/编辑器里持续打字，期间用托盘菜单切换免打扰、开关桌宠显隐 | 输入不中断、光标不丢失、焦点始终在编辑器 |
| C1 | 启动不抢焦点 | 当前窗口是编辑器时启动应用 | 桌宠出现但焦点不转移（`showInactive`） |
| C2 | 透明区穿透 | 把桌宠拖到某个可点击控件上，点击**虚线框之外**的窗口区域 | 点击作用于下层应用，桌宠无反应 |
| C2 | 本体不穿透 | 点击**虚线框之内** | 面板打开/关闭，下层应用无反应 |
| C2 | 快速掠过不粘滞 | 鼠标从本体高速划出窗口后立刻点击下层应用 | 点击生效（不被吃掉）—— 这是 `mouseleave` 兜底那段代码要防的破法 |

## 不应倒退（M0 顺带检查）

| # | 契约 | 操作 | 通过标准 |
|---|---|---|---|
| C3 | 不进任务栏与 Alt-Tab | 看任务栏；按 `Alt+Tab` | 桌宠不出现在任一处 |
| C8 | 一键静默 | 双击桌宠 | 托盘图标变灰调，状态角标转 `SLEEPY` |
| C9 | 可完全隐藏 | 托盘菜单「隐藏桌宠」 | 桌宠消失，托盘菜单仍可用（含退出） |
| C10 | 不留残影 | 任务管理器强杀主进程 | 桌面无残留的透明置顶窗口 |
| — | 拖拽与吸附 | 拖桌宠到屏幕边缘 30px 内松手 | 吸附贴边，且不被任务栏盖住 |
| — | 多显示器 | 拖到副屏后拔掉副屏 | 桌宠回落到主屏右下角 |

## 已知的 M0 缺口（不是缺陷）

- **C4 不遮挡全屏应用**：全屏检测属 M3，M0 未实现。
- **C5 默认无声 / C6 气泡自动消失**：气泡窗口属 M3，M0 不创建。
- **C7 休市零开销**：M0 只画静态首帧、无动画循环，天然满足；真正的验收要等 M3 动画接入后重做。
- **位置不持久化**：SettingsStore 属 M1，重启后桌宠回到主屏右下角。
- **无美术资源时**：`resources/pet/default/` 为空则显示几何占位形状、托盘用内置兜底图标。
  这是设计内的降级路径（[docs/06 §5](../06-桌宠交互与非干扰设计.md)），不影响 C1/C2 的验收。
