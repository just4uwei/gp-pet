# 形象设定 · default

本文件是 [docs/09 附录 A](../09-美术资源规格.md) 要求的《形象设定说明》。
docs/09 只管**形象无关**的规格；本文件承载「这只猫长什么样、九个动画怎么演」。

## 1. 概述

- 显示名：**小猫**
- 目录名 / `AppSettings.skin` 取值：`default`
- 形象类型：动物（家猫，Q 版比例，头身比约 1:1）
- 参考图：无。本套素材由 [`tools/asset-build/`](../../tools/asset-build/) 程序化生成，
  可编辑源即那份代码（不是 `.ase` / PSD —— 这是与 docs/09 §8 的偏差，见 §7）
- 朝向：固定正面朝向用户

## 2. 造型要点

| 部位 | 要点 |
|---|---|
| 整体 | 坐姿。头大身小，剪影是「圆头 + 梨形身体 + 右侧上翘尾巴」 |
| 头 | 椭圆（逻辑坐标 rx 21 / ry 18），两侧各一个颊部凸起，读起来是圆脸 |
| 耳 | 等腰三角，耳尖落在 `y = 8`（含描边到 7），内耳浅粉 |
| 额 | 三道短竖纹虎斑，用暗部色，位置压在 `y = 23` —— 贴头顶会读成刘海 |
| 眼 | 大圆眼。深色眼廓 + 蓝灰虹膜 + 深色瞳孔 + 左上 2×2 高光 |
| 鼻口 | 浅色口鼻块 + 粉色倒三角鼻 + ω 形嘴 |
| 须 | 每侧两根，起点压进剪影内 2 px，否则会读成浮在脸旁的两撇线 |
| 身 | 上半身椭圆的顶端（`y ≈ 49`）**必须压进头部底端（`y ≈ 54`）**，两者脱开就成了「浮在球上的一颗头」 |
| 胸 | 浅色胸口块 |
| 前爪 | 两只，比后半身多露 2 px，让脚在剪影上看得见 |
| 尾 | 从身体右后方伸出，向上翘，带一道暗色尾环 + 浅色尾尖 |

## 3. 调色板

对应 [`palette.json`](../../resources/pet/default/palette.json)。**描边色只有一个**：`#2A2028`。

| 用途 | 色值 |
|---|---|
| 描边（唯一） | `#2A2028` |
| 毛色 高光 / 主体 / 暗部 / 深暗部 | `#FDFBF5` `#EFE7DA` `#D9CDBB` `#B5A692` |
| 内耳 · 鼻 · 肉垫 | `#E8A0A8` |
| 虹膜 | `#5B7FA6` |

**为什么是奶白灰虎斑而不是橘猫**：docs/09 §1.3 把风险固定为暖橙、机会固定为金黄。
橘色毛发会和这两个语义色糊在一起，`alert` 举起的橙色小旗就看不出来了。
眼睛用蓝灰而非猫常见的琥珀或绿：琥珀撞语义色，绿撞 A 股跌色（§7.2）。

语义色在本形象中的落地位置：

| 语义 | 落点 |
|---|---|
| 风险暖橙 `#E8721C` / `#F59D4E` | `alert` 中举起的小旗旗面与亮部 |
| 机会金黄 `#F2C230` / `#F8DE7A` | `excited` 中头两侧的四角星芒 |
| 离线灰阶 四档 | `offline` 中四档毛色的一一对应去饱和映射 |

## 4. 道具

| 道具 | 出现的动画 | 是否属 §7.3 争议元素 | 处理方式 |
|---|---|---|---|
| 暖橙小旗（杆 + 旗面） | `alert` | 否 | 由抬起的右前爪握持；杆的上端定在 `y ≈ 52`，再往上会横穿颊部 |
| 金黄四角星芒 ×3 | `excited` | 否 | 头两侧 + 左上一枚小的，仅在跃起峰值之后出现 |
| 睡意「Z」 | `sleepy` | 否 | 脱离主体，深色字形 + 浅色外圈 |
| 无信号圆斜杠 | `offline` | 否 | 脱离主体，深色字形 + 浅色外圈 |

本形象**不含**任何武器、烟酒、宗教或政治符号，§7.3 不适用。
提示元素一律用星芒与旗子这类氛围隐喻，不含箭头、K 线、数字、货币符号（§7.1）。

## 5. 分镜落地

| 动画 | 本形象怎么演 |
|---|---|
| `idle` | 呼吸做成**上半身压缩 1 px**而不是整体上下弹 —— 基线必须钉死在 `y = 94`，差 1 px 就会「抖脚」。次级摆动交给尾巴：呼吸 4 帧一周期，尾巴 8 帧一周期，两者不同步 |
| `blink` | 主体零位移，只有眼部：睁 → 半闭（眼睑压下 + 一道深色睫线）→ 全闭（「‿」）→ 睁 |
| `look` | 只有头部及耳、须、眼随之横移，最大 ±2 px；躯干与尾巴完全静止 |
| `watching` | 耳朵竖起 2 px + 眼睛放大（rx 4.5→5、瞳孔缩小）+ 头下沉 1 px 前倾；呼吸只在 6 帧里出现 1 帧，比 idle 的 4/8 明显更浅 |
| `excited` | 蓄力 `Δy=+2` → 跃起 → 峰值 `Δy=−3`（f5–f6）→ 落地 → 回稳。离地 5 帧。眼睛转「^^」、嘴转笑；金黄星芒 f7 出现、f10 消失，末帧与 idle 首帧一致 |
| `alert` | 戒备特征是**耳朵后压 + 眯眼**，与 `watching` 的竖耳睁眼正好相反，一眼可区分方向性。整体零位移（基线不许动），只有小旗逐帧左右摆 1 px。小旗 f1 出现并持续到末帧 |
| `sleepy` | 耳朵垂下、闭眼、头下沉 2–3 px；f4 张口打哈欠。相邻帧位移 ≤1 px（4 fps 下大位移会明显卡顿）。「Z」逐帧上浮 |
| `offline` | 姿态与 idle 首帧同，仅换色 + 垮耳。**眼睛保持睁开** —— 闭眼会和 `sleepy` 撞车，而「离线」的语义是「醒着但看不到数据」。断线图标显示 2 帧、隐藏 2 帧 |
| `shush` | 猫没有手指，以**抬起前爪抵住嘴边 + 嘴转为一条平线 + 半闭眼**表达「安静」（§1.2 允许的等效手段）。爪子抬到下巴附近（lift 24），比 `alert` 举旗的 lift 12 高得多 |

## 6. 无法直接表达的契约

只有一条：`shush` 的「食指抵唇」。猫无手指，改用上表所述的等效手势（§1.2 允许，须在此写明）。

## 7. 偏差说明

| # | 与 docs/09 的不一致 | 原因 |
|---|---|---|
| 1 | 可编辑源文件不是 `.ase` / 分层 PSD，而是 `tools/asset-build/` 下的生成代码 | 素材由程序生成而非手绘。代码就是分层源：形象、分镜、调色板分别在 `character.mjs` / `animations.mjs` / `palette.mjs`，改一处即可全套重出。**同时也是与 CLAUDE.md「资源是外包件，不在仓库里手搓」的偏差**，由项目所有者明确要求 |
| 2 | A9（主体包围盒尺寸）只在 `idle`/`blink`/`look`/`watching`/`shush` 上校验 | §2.2 允许道具延伸至画布边缘，但 A9 measure 的是全部非透明像素。带道具的 `excited`/`alert`/`sleepy`/`offline` 若一并校验，等于禁止道具外扩，与 §2.2 自相矛盾。校验器对此有显式注释 |
| 3 | `icon.ico` 的各尺寸条目一律用 PNG 压缩形式，未使用 BMP/DIB | Windows Vista 起支持；本产品只面向 Windows 10/11（docs/01） |
| 4 | 48 / 64 / 128 三个 ico 尺寸由 16/32 猫头与全身图**整数倍最近邻放大**得到 | §6.2 禁止的是**降采样**（必糊）。整数倍放大对像素画无损，且保持了「小尺寸用局部特征、大尺寸用全身」的分档 |
