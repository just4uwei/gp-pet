# ADR-0002 · 行情数据源采用公开接口 + 多源冗余

- **状态**：已接受
- **日期**：2026-08-11

## 背景

需要 A 股日线与实时快照。产品要求「免登录、零配置、本地存储」，因此数据源不能强制用户注册或申请 token。

## 候选

| 方案 | 优势 | 劣势 |
|---|---|---|
| **东财/新浪/腾讯公开接口** | 免注册、免费、无配额门槛；日线+快照+分钟线齐全；批量快照支持好 | 非官方接口，字段可能变动或被封；无 SLA；无官方文档 |
| Tushare Pro | 字段规范、有复权因子与财务数据；文档完善 | 需 token；免费额度受积分限制；实时性弱，分钟级需高积分；违背零配置目标 |
| 券商开放平台 | 数据权威 | 需开户与鉴权；与「不接券商」的安全边界冲突 |

## 决策

采用**公开接口为唯一出厂数据源**，东财为主，新浪与腾讯为备。不内置 Tushare。

## 理由

1. 零配置开箱即用是产品定位的一部分——要求用户先去申请 token 会劝退绝大多数目标用户。
2. 三源冗余 + 自动降级，可用性反而高于单一 token 源。
3. 本项目只读行情、不下单、请求量小（每日 < 1000 次），在合理使用范围内。

## 应对非官方接口的脆弱性

这是本决策的主要风险，用四条措施对冲：

1. **适配层隔离**：`QuoteProvider` 接口统一，各源的 URL 与字段映射封闭在各自模块内。换源不影响上层。
2. **fixture 驱动的集成测试**：把每个源的真实响应录制为 fixture，接口字段变动会让测试立刻失败并指明位置。设计文档**不写具体 URL 与字段**，避免文档腐化。
3. **健康度可视化**：降级与失败写入 `provider_health`，面板可查。故障对用户是可见的，不是静默的错误数据。
4. **跨源一致性抽检**：两源同时可用时比对最新价，偏差 > 1% 告警。静默的错误数据比请求失败危险得多。

## 自我限制

不因免费而滥用：全局并发 ≤ 4、快照必须批量、日线只做增量、休市不发请求、开启 keep-alive。详见 [03 §2.4](../03-数据源与存储设计.md)。

## 后续

若用户有严格回测需求，可在设置中开放**可选**的 Tushare token 作为增强源（用于复权与更长历史），但绝不作为默认路径。
