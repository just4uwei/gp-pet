# 蹲点 · 设计文档索引

## 三条贯穿全局的原则

1. **不干扰是硬指标，不是体验优化。** [06 §1](./06-桌宠交互与非干扰设计.md) 的十条契约每次发版都要逐条验收。
2. **参数由本地回测标定，不由转述决定。** 见 [ADR-0003](./adr/ADR-0003-来源文档数值不作为出厂默认.md)。
3. **引擎是纯函数库。** `src/core` 不碰 Electron、不碰 IO、不读时钟，未来函数由架构消除。见 [ADR-0004](./adr/ADR-0004-核心引擎与-electron-解耦.md)。
